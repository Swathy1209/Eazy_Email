## 3. AI Subject Line Optimiser API (F2)

Method: POST  
Endpoint: /api/ai/subject-lines  

### Request Schema

```json
{
  "brief": "string (required, non-empty)",
  "industry": "string (optional)",
  "targetRole": "string (optional)",
  "country": "string (optional)",
  "tone": "string (optional, default: professional)"
}
```

Validation rules:
- `brief` must be a non-empty string after sanitization.
- `industry`, `targetRole`, `country` are optional but sanitized when present.
- `tone` is optional and sanitized.
- Input safety removes prompt-injection phrases: `ignore previous`, `system prompt`, `act as`.

### Response Schema

Success:
```json
{
  "success": true,
  "subjectLines": [
    {
      "style": "Curiosity",
      "subject": "What could improve your qualified pipeline this month?",
      "score": 8,
      "reason": "Curiosity framing drives opens."
    }
  ]
}
```

Failure:
```json
{
  "success": false,
  "error": {
    "message": "brief is required and must be a non-empty string.",
    "code": "VALIDATION_ERROR"
  }
}
```

### Edge Case Handling

- Always returns exactly **5** subject lines.
- Invalid AI JSON / parse failure: retries once, then graceful fallback set.
- AI timeout: capped to 8 seconds per attempt.
- Missing fields from AI output are defaulted:
  - `style: "General"`
  - `score: 5`
  - `reason: "Generated by AI"`
- Score is clamped to `1..10`.
- Empty subjects are removed.
- Duplicate subjects are removed (case-insensitive).

### Pipeline Integration (CSV)

Each processed CSV row now emits:

```json
{
  "openingLine": "string",
  "email": "string",
  "subjectLines": [
    { "style": "Curiosity", "subject": "...", "score": 8, "reason": "..." }
  ]
}
```

Worker behavior for production stability:
- Batches rows (`CSV_PROCESS_BATCH_SIZE`, default `5`).
- Adds inter-batch delay (`CSV_BATCH_DELAY_MS`, default `300`) to reduce provider rate-limit spikes.
- Handles missing row fields with generic fallbacks in context and subject brief construction.

Used by:
- Subject line selection screen
- CSV personalization pipeline output

Depends on:
- Prompt builder + AI provider abstraction
- Normalization and fallback utilities
